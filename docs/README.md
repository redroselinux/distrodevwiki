# Welcome Linux Distro Dev Wiki

This wiki explains how to make a Linux distro from scratch. It is similar to LFS, but not assuming a single-user system. It is made by the creators of Redrose Linux.

## Requirements

- Comfortable with the command-line
- Basic understanding of compiling software
- Knowing a programming language (needed for a full distro)
