# Welcome Linux Distro Dev Wiki

This wiki explains how to make a Linux distro from scratch. It is similar to LFS, however it does not expect you are the only person who wants to use your system. The wiki is made by the creators of Redrose Linux.

Get yourself ready by:

- Being comfortable in the command-line
- Knowing how compiling software works
- Knowing a programming language (if you are actually making a full distro)
